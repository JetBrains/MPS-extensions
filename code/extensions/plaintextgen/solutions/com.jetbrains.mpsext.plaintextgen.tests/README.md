# PlainTextGen regression suite

In the extensions project, make `com.jetbrains.mpsext.plaintextgen.tests`, then
run its test cases as MPS tests. The solution is registered in the native test
build; new tests in its models need no separate build registration.

The suite covers fallback/override precedence, default compatibility, isolation,
layout, indentation, tabs and whitespace, filenames, charsets, parser behavior,
generator macros, and PlainTextFlow reductions. It is not exhaustive coverage of
editor actions or arbitrary language compositions.

Add layout templates to `layouts` and use
`PlainTextGenAssertions.assertText(project, template, fileName, encoding,
expectedText)`. This local adapter only copies fixtures into temporary models
and delegates exact byte/metadata checks to the shared comparator assertions.
Select fixtures by name, not root order. `OutputAssertions` covers rejection paths.
Keep each scenario's input, production call and native test assertions in its
test method; helpers provide fixture setup, generation or reusable byte assertions,
not a scenario dispatcher. Access fixture links and properties through smodel,
and use typed `LineEnding`/`LineEndingOverride` enum members for override matrices.

For generator comparisons, use the existing comparison-language assertions, as
in `Generator`. Its checked-in expected snapshot is independent of the generator
template and selects `map_TestConcept`. `GeneratedText` covers nested/empty loop
and property macros, tabbed/mixed templates, and PlainTextFlow using the existing
`GeneratorFacade` and `TextComparison` APIs. These text expectations normalize
CRLF to LF; byte-exact tests do not.

`MacroOverrides` runs model-to-model generation with real property macros on the
example's `map_TestConcept` template. The queries read the input root's optional
`modelLineEnding` and `settingsLineEnding` properties. Exact generated bytes are
compared with the independent expected snapshot configured directly with the same
overrides. Cases cover inherited fallback, settings override, and conflicting
model/settings values. Direct textgen tests separately establish precedence.

Paste tests call the explicit-text `PlaintextPaster` overloads rather than the
clipboard. They cover indentation detection, intermediate dedents, blank lines,
CRLF, tab expansion/preservation, and empty/null input.

`LineEndingAssertions.withFixture`, `MacroOverrideAssertions.withFixture`, and
`PasteAssertions.withFixture` share fixture copying, configuration, and disposal.
Their callbacks keep each scenario's actions, expected values, and assertions in
the named test method. Temporary models use independent non-reloadable modules
so adding fixture imports cannot change the source module's dependencies.

`rightAlignedIndentationKeepsHistoricalPadding` intentionally records historical
extra padding, tracked in [#1941](https://github.com/JetBrains/MPS-extensions/issues/1941).
Update its expectation together with a fix for that issue; this compatibility
baseline is not intended to prevent correcting the behavior.
